# SuriJava Flavours – website

Dit is een volledig statische website. Er is geen betaalde software of database nodig.

## Gratis testen
Open `index.html` in Chrome/Edge om de website lokaal te bekijken.

## Gratis online zetten
Je kunt deze map gratis publiceren met bijvoorbeeld GitHub Pages of Netlify. Een eigen domeinnaam zoals `surijavaflavours.nl` is optioneel en kan wel geld kosten.

## Aanpassen
- Teksten/prijzen: `index.html`
- Afbeeldingen: `assets/`
- Telefoonnummer/WhatsApp: zoek in `index.html` naar `31626100008`

## Belangrijk
De huidige website gebruikt de aangeleverde prijslijsten als visuele content. Voor catering wordt in de tekst aangegeven dat grotere partijen en maatwerk een persoonlijke offerte krijgen.
